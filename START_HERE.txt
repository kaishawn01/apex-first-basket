APEX FIRST BASKET DASHBOARD V2.2.0

1. Extract the ZIP into a new folder on your Desktop.
2. To reuse your 36 saved games, COPY the data folder from your old engine
   into the new APEX_First_Basket_Engine folder before starting.
3. Double-click START_APEX.bat. First launch installs dependencies in .venv.
4. Your browser opens the dashboard. Leave the command window running.
   If the browser does not open, visit http://localhost:8501.
5. Enter your API keys in Settings, then click Apply settings.
6. Sync history if needed, then Load slate & projected starters.
7. Refresh injury reports. Replace any wrong starter using the dropdown.
8. Confirm each team's announced five, fetch odds, then run rankings.

Keys stay in memory unless you choose Remember keys. That option writes an
unencrypted .apex_keys.json on your computer. Do not share that file or a copy
of your app folder containing it. The supplied ZIP contains no credentials.

Projected starters are NOT official confirmed starters. Injury reports do
not identify replacements. Confirmations reset when you reload the slate,
change the date or selected five, or restart the dashboard.

The model is experimental. Expect HOLD: SAMPLE early in the season.
BALLDONTLIE and Odds API calls require your own active keys and coverage.
No automated bets are placed. Close the command window to stop the app.

V2.1 NEW FEATURES
Expand Build deeper history to import prior-season games in resumable batches.
Start with 250 games, then run the Backtest lab evaluation. Data quality shows
team coverage and any malformed history. Current-season starts appear separately.

UPDATING AN EXISTING INSTALLATION
Close APEX, then copy this ZIP's program files into your existing engine folder
and replace matching files. Do not delete your data, .venv, or .apex_keys.json.
This ZIP contains none of those local items. Relaunch START_APEX.bat.

V2.2.0 includes a GitHub updater. Read GITHUB_SETUP.txt first for setup.
